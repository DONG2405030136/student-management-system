# 豆包 AI 提示词（考试查点 1）

> 本文件记录本项目在豆包（Doubao）中使用的完整提示词，包含**总提示词**与**分阶段迭代提示词**。
> 使用方法：将总提示词粘贴到豆包对话（或 Trae CN 的 AI 对话框）→ 按阶段提示词逐步迭代 → 把生成的代码放入 Trae CN 工程中调试运行。

---

## 一、总提示词（初始提问，一次问清全部需求）

```
我是一名高职学生，正在完成《大数据与云计算》课程期末考核任务，需要你帮我搭建一个可以交互的前后端学生信息管理系统。请严格按照以下要求生成完整的项目方案与代码：

【角色设定】
你是一名资深全栈工程师，熟悉 Vue3、Element Plus、Node.js、Express 与 SQLite 数据库，擅长搭建界面美观、功能完整的管理系统。

【技术栈要求】
1. 前端使用 Vue 3 + Vite + Element Plus + ECharts + Vue Router + Pinia + Axios；
2. 后端使用 Node.js + Express；
3. 数据库使用 SQLite（本地文件数据库，无需单独安装数据库服务）；
4. 登录认证使用 JWT Token，密码使用 bcryptjs 加密存储。

【功能要求】
1. 系统至少包含三种用户角色：管理员、教师、学生，不同角色登录后看到不同的菜单与功能；
2. 管理员：学生管理、班级管理、教师管理、课程管理、成绩管理、考勤管理、账号管理，支持增删改查、搜索、分页；
3. 教师：查看我的课程、录入成绩、录入考勤；
4. 学生：查看我的信息、我的成绩、我的考勤；
5. 仪表盘：使用 ECharts 展示学生人数、性别分布、成绩分数段、课程平均分等统计图表；
6. 登录页美观，支持角色演示账号，全程交互式登录。

【部署要求】
1. 全程本地部署、本地使用，不依赖外网服务；
2. 前端开发服务器配置代理，/api 请求转发到后端；
3. 项目要有清晰的目录结构、README 说明文档、一键启动脚本；
4. 代码要完整可直接运行，最终需要上传到 GitHub 开源仓库。

【交付内容】
请分阶段给出：①项目结构设计 ②数据库表设计（含建表语句）③后端接口清单 ④前端页面清单 ⑤完整可运行代码 ⑥运行步骤说明。
```

## 二、分阶段迭代提示词

### 阶段 1：数据库与后端（粘贴给豆包）

```
请按以下设计创建后端项目：Node.js + Express + better-sqlite3。

数据库表：users（用户账号）、classes（班级）、teachers（教师）、students（学生）、
courses（课程）、course_classes（课程班级关联）、grades（成绩）、attendance（考勤）。

要求：
1. 表结构包含外键关联：学生属于班级、课程属于教师、成绩关联学生与课程、考勤关联学生与课程；
2. 提供建表 SQL 和演示数据（3 个教师、4 个班级、20 个学生、6 门课程、若干成绩与考勤）；
3. 演示账号：admin/123456（管理员）、teacher1/123456（教师）、student1/123456（学生），密码用 bcryptjs 加密；
4. 后端接口包含：登录（返回 JWT）、学生增删改查（分页搜索）、班级、教师、课程、成绩、考勤、账号管理、仪表盘统计；
5. 提供 auth 中间件做 JWT 校验，并提供角色权限控制（管理员/教师/学生访问不同接口）。
```

### 阶段 2：前端骨架与登录（粘贴给豆包）

```
请创建 Vue 3 + Vite + Element Plus 前端项目，要求：
1. 登录页：渐变背景、系统 Logo、用户名密码、演示账号快捷填充按钮；
2. 登录后主布局：左侧深色侧边栏菜单（按角色动态显示）、顶部面包屑与用户下拉（个人中心/退出登录）；
3. 封装 axios 请求：自动携带 JWT Token、统一错误提示、401 自动跳转登录页；
4. 路由守卫：未登录跳转登录页，角色不匹配跳转首页；
5. 登录接口对接后端 /api/auth/login，保存 token 到 localStorage。
```

### 阶段 3：管理功能页面（粘贴给豆包）

```
请开发以下管理页面（Element Plus 组件，风格统一、界面美观）：
1. 仪表盘：顶部统计卡片（学生/教师/班级/课程/成绩数量）+ ECharts 图表（各班级人数柱状图、性别分布饼图、成绩分数段柱状图、课程平均分折线图）；
2. 学生管理：搜索（姓名/学号）、按班级筛选、分页表格、新增/编辑对话框、删除确认、导出 CSV；
3. 班级管理、教师管理、课程管理：列表 + 新增/编辑/删除；
4. 成绩管理：按课程/班级筛选、成绩统计标签（平均分/最高/最低/及格率）、批量录入成绩；
5. 考勤管理：按课程/日期筛选、批量录入（出勤/迟到/请假/缺勤）；
6. 账号管理：账号列表、新增账号、重置密码、启用/禁用。
```

### 阶段 4：教师端与学生端 + 测试完善（粘贴给豆包）

```
1. 教师端：我的课程列表、成绩录入页（选择课程→学生列表→填分→一键保存，实时统计平均分）、考勤录入页（选择课程日期→标记状态→保存）；
2. 学生端：我的信息（档案卡 + 系统说明）、我的成绩（成绩单表格 + 平均分/最高分/及格率统计卡片）、我的考勤；
3. 个人中心：查看资料、修改密码；
4. 全系统统一处理：空数据提示、加载中状态、操作成功/失败提示；
5. 自查清单：管理员登录后能看到全部菜单并完成增删改查；教师只能看到自己的课程；学生只能看到自己的成绩与考勤；错误密码无法登录。
```

## 三、提示词使用记录（写报告时可直接引用）

| 阶段 | 提示词要点 | 豆包输出 | 人工修改 |
| --- | --- | --- | --- |
| 1 | 后端 + 数据库表设计 | 生成 Express 路由与建表语句 | 补充演示数据、统一返回格式 {code,msg,data} |
| 2 | 前端登录与布局 | 生成 Vue 页面与 axios 封装 | 补充路由守卫角色判断 |
| 3 | 管理功能页面 | 生成各管理 CRUD 页面 | 增加统计标签、导出 CSV |
| 4 | 教师端/学生端 | 生成角色页面 | 修正成绩等级颜色、空数据提示 |

> 生成过程中如遇报错（如端口占用、模块缺失、跨域问题），在 Trae CN 中查看报错信息后让豆包协助修复，并记录到报告"报错排查"部分。
